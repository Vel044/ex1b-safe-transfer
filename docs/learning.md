# 核心模块学习顺序

1. 从`server/ex1b/protocol.py`和Swift的`Protocol.swift`开始：解释为何TCP没有消息边界，按共享fixture手算20字节报头以及中文UTF-8长度。
2. 阅读`Connection.swift`及服务端accept流程：区分TCP keepalive、应用心跳、TLS证书链、主机名验证、双向身份验证和账户授权。
3. 对照上传时序跟踪DATA、文件fsync、SQLite提交、ACK的顺序。思考ACK提前发送时，进程崩溃会丢失什么。
4. 对照下载时序解释为什么由客户端保存续传偏移；在最后一次ACK丢失后，两端如何重新达成一致。
5. 阅读`storage.py`和`Disk.swift`：说明字符串检查与目录描述符访问各自解决的问题，为什么符号链接检查后再普通open仍有竞态。
6. 阅读`TransferEngine.swift`：区分请求编号和持久传输编号，观察多个文件如何交替请求，以及暂停和重启如何恢复。
7. 阅读令牌桶和配额事务：计算512KiB/s下两连接发送2MiB的理论最短时间，解释首个64KiB突发额度。
8. 运行测试后逐项说明预期结果。答辩时明确资源限制的适用范围，不宣称应用代码能够阻止所有DDoS。

实验记录应填写实际发生的环境、结果及问题。可从“初始依靠连接关闭判断传输结束的局限”“重启检查点与完成提交之间的崩溃窗口”“文件夹操作复用单文件协议”等问题展开讲解。
