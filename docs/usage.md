# SFT1 Transfer 使用说明

请先按照[安装与启动](installation.md)完成服务端启动、客户端编译和证书连接。本文介绍连接成功后的功能操作。以下终端命令均在项目根目录执行。


## 1. 界面和目录浏览

- **左侧本地文件**：点击 **选择目录…**，通过系统选择器授权本地目录。此目录也是本地浏览和下载的起点。
- **右侧服务器文件**：显示当前账户的远端目录。双击目录可进入，点击上箭头返回上一级；点击表头可排序。
- **下方传输队列**：显示任务、进度、大小、速度和状态。选择任务后，底部会显示详细结果或错误原因。
- **底部状态栏**：显示连接状态、账户身份和带宽上限。

两侧目录栏都有新建文件夹按钮，可在当前所在目录下新建目录。文件列表支持多选。

## 2. 上传文件

1. 在左侧选择本地目录，进入文件所在位置。
2. 在右侧进入要保存文件的服务器目录。
3. 在左侧选中一个或多个文件，点击工具栏 **上传**。
4. 在下方队列查看进度和结果。文件传完并通过 SHA-256 校验后，状态显示 **已完成**。

文件上传到**右侧当前打开的目录**。如果远端已有同名文件，任务会失败并提示改名；现有文件不会被覆盖。

## 3. 下载文件

1. 在左侧选择并进入要保存下载文件的本地目录。
2. 在右侧进入服务器目录，选中一个或多个文件。
3. 点击工具栏 **下载**，在传输队列查看结果。

文件保存到**左侧当前打开的目录**。本地已有同名文件时，任务会提示冲突；可以改名或选择其他目标目录后重新添加。

## 4. 整文件夹传输

上传时在左侧选中文件夹本身，再点击 **上传**；下载时在右侧选中文件夹，再点击 **下载**。目录层级和空目录会保留。已有同名目录可以合并，同名文件仍会提示冲突。

文件夹会展开为多个目录和文件任务；某个文件失败后，其他任务仍可继续。符号链接会跳过并在界面提示。默认目录深度上限为 32 层，每组最多 10000 个条目。

## 5. 多任务和进度

可以一次多选多个文件，也可以在已有任务执行时继续添加上传或下载任务。每个账户最多同时传输 4 个文件，其余任务在队列中等待。进度、速度和完成情况分别显示在每条任务中。

## 6. 暂停、继续和断点续传

在队列中选中任务，点击 **暂停**；需要继续时选中该任务并点击 **继续**。可多选任务，操作只作用于选中的任务。

网络断开时，客户端会尝试重连；重连后可手动继续未完成任务。客户端或服务端重启后，任务记录和检查点可用于继续传输。恢复前会检查文件身份和已有数据；源文件发生变化或临时文件损坏时，需要取消旧任务并重新添加。

## 7. 取消任务和查看失败

选中任务点击 **取消**。已经完成的文件保留，未完成的临时数据会清理；离线取消会在重连后同步到服务端。

**删除所选**可移除选中的已完成或已取消记录；**清理已结束**可一次清理这些记录。未完成任务应先取消，失败任务可继续或取消。目录任务被其他未结束任务依赖时暂不删除。

队列顶部显示完成和失败数量。勾选 **仅失败** 可以查看失败任务；选中任务后，在队列下方查看具体原因。处理原因后可继续或重新添加任务。

## 8. 用户隔离和带宽限制

Alice 和 Bob 的服务器目录相互独立。切换身份时，断开连接，在连接窗口选择另一个用户的 P12 身份及密码。

| 默认账户 | 带宽上限 | 存储配额 |
| --- | --- | --- |
| Alice | 2 MiB/s | 2 GiB |
| Bob | 512 KiB/s | 2 GiB |

同一账户的上传、下载和所有连接共享其带宽上限；单文件默认上限为 1 GiB。管理员可在项目根目录执行以下示例，将 Bob 的上限设置为 1 MiB/s：

```sh
docker compose exec -T server ex1b admin --data /data set-bandwidth bob 1048576
```

## 9. 完整性与安全边界

传输使用双向 TLS 验证身份和加密通信。接收方先保存临时文件，检查完整长度和 SHA-256 后才提交正式文件。服务端限制账户访问范围，并设置连接、报文、配额、超时及速率上限；这些应用层限制无法阻止网络带宽被大流量完全占满。

实验私钥、P12 密码和用户数据保存在被 Git 忽略的运行目录；公开代码或提交源码包时，应继续排除这些文件。实验 CA 未部署完整的公开证书撤销服务，客户端身份可通过禁用账户控制。应用采用本地临时签名，未进行开发者公证。

## 10. 拖放、复制粘贴和删除

左右文件栏的中间分隔线可拖动调整宽度，上下分隔线可调整队列高度。选中一个或多个文件后，从任意选中行拖到另一栏即可加入上传或下载队列，目标是该栏当前打开的目录。拖到另一栏后，整张目标表格会显示系统接收反馈，松手后开始加入队列；支持文件和文件夹、多选拖动。当前支持本应用双栏之间拖放。

通过文件列表右键菜单的“复制”“粘贴”，或聚焦列表后使用 ⌘C、⌘V，可以在两栏之间传输，也可以先复制、进入同侧其他目录后粘贴。同名文件拒绝覆盖；目录复制逐项执行，失败时保留已复制内容。

本地删除使用系统废纸篓，远端删除为永久删除；两者操作前都有系统确认窗口。远端路径存在未结束的传输记录时，需要先完成或取消。右键菜单作用于所选项目；删除快捷键为 **⌘⌫（Command＋Delete）**，仅在文件列表获得焦点且有选中项目时生效；只按 Delete 不删除文件。

## 11. 证书账户的 r/rw 权限

客户端证书指纹绑定到账户，服务端数据库决定权限。`r` 允许浏览和下载；`rw` 还允许上传、新建、复制及删除。证书文件名不决定权限，修改客户端不能绕过服务端检查。已有账户迁移后默认 `rw`，可按需修改，例如将 Bob 设为只读：

```sh
docker compose exec -T server ex1b admin --data /data set-access bob r
```

恢复读写：

```sh
docker compose exec -T server ex1b admin --data /data set-access bob rw
```

服务端每次请求都重新读取权限；客户端连接时及心跳后更新权限显示和按钮状态。

本地文件或文件夹右键选择“在 Finder 中显示”可定位所选项目；本地目录栏的 Finder 按钮打开当前目录。右键“打开目录”只在单选文件夹时显示，普通文件不显示此项。

### 取消账户带宽限制

管理员可将 bandwidth 设为 0，表示不限速，客户端状态栏显示“不限速”。非零值仍至少为 65536 字节/秒。

```sh
docker compose exec -T server ex1b admin --data /data set-bandwidth alice 0
docker compose exec -T server ex1b admin --data /data set-bandwidth bob 0
```
